# AI-Powered-Deep-Fake-Video-Detection-Using-BI-LSTM-for-Strengthening-Social-Media-Security
AI-powered Deepfake Video Detection System using EfficientNet, Vision Transformer (ViT), and BiLSTM for real-time video authentication. Supports video uploads and YouTube URLs, providing fake/real classification, confidence scores, and authenticity reports to strengthen social media security.
